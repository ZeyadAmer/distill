## 3. Launch sale ($4.99 for about 1 month)

Pro is a non-consumable IAP, so the price is set on the IAP, not on the app.

App Store Connect → Hotstash → Monetization → In-App Purchases → Pro → Price Schedule → Add Pricing:
- Start: launch day, price $4.99 (Apple adjusts the other storefronts automatically; check EGP).
- Add a second change on day 30 back to $9.99. **Set this when you set the sale, so it can't be forgotten.**

The App Store shows no strikethrough or "sale" badge, so the sale only works if you announce it: promo text, What's New, and the posts below.
